# Personal Portfolio Website

This repository contains the source code for my personal portfolio website, hosted using **GitHub Pages**.  
The site showcases my projects, experience, achievements, and provides ways to get in contact with me.

## Features

- **About Me** – A brief introduction and background
- **Projects** – Highlights of my technical and academic work
- **Achievements** – Scholarships, publications, certificates
- **Curriculum Vitae** – Downloadable CV + PDF preview
- **Contact Form** – Functional email form using Formspree
- **Responsive Design** – Looks good on desktop, tablet, and mobile

## Technologies Used

- **HTML5** & **CSS3**
- **JavaScript** (light usage)
- **Formspree** for email submission
- **GitHub Pages** for hosting
